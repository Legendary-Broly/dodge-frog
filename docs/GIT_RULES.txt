# Git Rules

## Temporary Enforcement Note

This repository is currently private on a free GitHub account, so GitHub does not enforce branch protection or rulesets.

Until we upgrade or move plans, these rules are enforced by team process:

- Do not push directly to main.
- Do not push directly to dev unless agreed.
- Work in feature branches.
- Open pull requests into dev.
- Brandon merges into main only when a stable milestone is reached.

## Branches

- main is protected.
- No direct pushes to main.
- Work happens in feature branches.
- Merge through pull requests.

## Branch Naming

Examples:

- feature/player-movement
- feature/car-spawner
- feature/item-boxes
- feature/finish-line
- fix/player-stumble-bug

## Commit Rules

Good:

- Add basic player sprint
- Add car spawn timer
- Fix crown not attaching to leader

Bad:

- stuff
- updates
- Brandon broke everything again
- final final real

## Merge Rules

- Pull request required.
- At least one other person reviews.
- Do not merge broken scenes.
- Do not commit giant assets
